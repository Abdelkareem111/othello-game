# Othello Game (Reversi) — Pygame Edition

Welcome to **Othello**, a strategic board game built with **Python** and **Pygame**. This project brings the classic two-player Reversi experience to your screen, complete with smart AI opponents, multiple difficulty levels, and a friendly user interface.

## Features

- **Two Game Modes**:
  - Player vs. AI (with difficulty selection)
  - Player vs. Friend (local multiplayer)

- **AI Difficulty Levels**:
  - *Easy*: Makes random moves, ideal for beginners.
  - *Medium*: Makes reasonably smart moves with occasional errors.
  - *Hard*: Plays with strategy and minimal randomness.

- **Interactive UI**:
  - Main menu and difficulty selection screen
  - Real-time piece placement and turn tracking
  - Animated hover effects on buttons
  - End-game screen with winner announcement and final score

- **Smart AI Logic**:
  - AI evaluates moves based on board position, corner control, and flips
  - Adjustable randomness based on difficulty
